# pusto.sk

Platform for classified ads in Slovakia.

## Features
- User authentication
- Listings system
- Telegram scraping
- auto filter by morphirial method 
- checking for duplicates by photo hashes, text and nicknames by score system 
- translate on English and Slovak languages 
- posting on site clear adv

## Tech stack
- Django
- PostgreSQL
- DRF

## How to run

git clone https://github.com/you/pusto-sk
pip install -r requirements.txt
python manage.py runserver
